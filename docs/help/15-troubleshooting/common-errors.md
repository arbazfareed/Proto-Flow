# Common errors

If a project fails to open, check that it is a valid `.pflow` file and that the file is complete. ProtoFlow validates imported project data and reports schema issues; preserve a copy of the original before attempting recovery.

If a widget or interaction appears incorrect, verify the selected screen and breakpoint, widget visibility and layer order, rule conditions, and action targets. Use Preview to reproduce the behavior from a clean runtime state.

If an online feature fails, check network status, credits, and the service message shown in the dialog. Local design and local export remain available without a cloud connection.

For persistent errors, export sanitized logs from **Privacy & diagnostics** and include the steps to reproduce in a support report. Never include project files, credentials, or customer data in a public issue.
