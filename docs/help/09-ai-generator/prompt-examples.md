# AI prompt examples

Describe the trigger, any condition, and the intended result. Specific, short prompts are easier to review than broad requests.

Examples:

- “When this button is clicked, navigate to the Details screen.”
- “On click, add one to the `count` variable and show the updated value.”
- “When this control is clicked, set the Tabs panel to its Activity state.”

Check that the referenced screen, variable, panel, and state exist. Treat the generated rule as a draft; review and test it before relying on it.
