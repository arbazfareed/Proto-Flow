# How the AI interaction generator works

The interaction generator can draft a rule from a plain-language description. Select a widget, describe the desired interaction, and review the proposed event, conditions, and actions before applying it.

Generation is an optional cloud-backed action and may use wallet credits. It does not replace checking the rule: confirm its targets, values, and ordering, then test the result in Preview.

If generation is unavailable, create the same rule manually in the interaction builder. Do not put secrets or personal data in a prompt.
