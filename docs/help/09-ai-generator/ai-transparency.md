# AI transparency: what is sent

When you explicitly run the AI interaction generator, ProtoFlow sends your prompt and the interaction context needed to draft a rule to the configured cloud service. The request is made only for that action; local canvas editing and local Preview do not send project content to the AI service.

Do not submit secrets, personal data, customer information, or a full project export in a prompt. Review the privacy policy and the confirmation or cost information shown by the app before using a cloud-backed action.

The generated rule is returned to the editor for your review. It is not applied as a trusted result: inspect it and test it in Preview.
