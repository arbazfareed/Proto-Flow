# Starting and joining a collaboration session

Open **Collaborate** to create a session or join an existing one. The dialog shows session and permission details before you connect. Collaboration requires a network connection and may use wallet credits; check the current dialog for cost and availability.

Share the invite with intended participants only. Sessions have an inactivity expiry, which the dialog explains. Close the session when collaboration is complete.

If a connection fails, verify network access and session validity. Local project editing remains available when you are not connected to a collaboration session.
