# Multi-cursor, presence, and permissions

During an active collaboration session, participant presence and cursors help show who is working in the shared project. The collaboration dialog displays connected participants and provides the available view/edit permissions.

Use view-only access when someone needs to review rather than modify the prototype. Session changes synchronize through the collaboration service; avoid using collaboration for projects you cannot share with the other participants.

Presence depends on a live connection. If a collaborator disappears, check the session status and network before assuming their project changes were saved.
