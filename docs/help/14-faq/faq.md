# Frequently asked questions

## Is ProtoFlow free?

Local authoring, saving, Preview, and local HTML export work without cloud credits. Some optional cloud actions are metered.

## What are credits?

Credits are used by certain cloud-backed actions. The wallet and action dialogs show current balances and costs.

## Do I need an account?

No account is needed for local projects. Account linking is optional and used by account-backed services.

## What if I run out of credits?

Wait for an eligible daily refill or use local workflows. The wallet shows refill availability and the current cap.

## Where is my data stored?

Project files are stored where you save them. Local browser/app state is stored on the device. Cloud features transmit the data required to perform the selected action; see the privacy policy.

## Can I use it commercially?

Check the current license and applicable third-party asset licenses before commercial use. This guide is not legal advice.
