# Symbols and reusable components

Create a symbol from selected widgets to save a reusable master in the Symbols library. Place symbol instances on screens, then update the master to propagate shared design changes. This helps keep repeated controls and patterns consistent.

Detach an instance when it needs to become independent, or swap its symbol reference when reusing the same placement with a different master. Instance transforms and supported text overrides can be adjusted separately.

Deleting a symbol detaches its instances rather than leaving unresolved references. Use the Symbols library to rename masters and manage reusable components.
