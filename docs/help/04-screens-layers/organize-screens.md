# Organizing screens

Screens are listed in the left sidebar. Select a screen to make it active, and use the screen actions to rename, duplicate, reorder, or remove it. Each screen keeps its own widgets, device settings, breakpoint definitions, and optional Flow position.

Use descriptive names for screens and group related flows in a consistent order. The start screen is the entry point for Preview; navigation rules connect it to other screens.

Deleting a screen removes it from the project. Navigation actions that point to a removed screen are not displayed as Flow edges, so review interactions when restructuring a prototype.
