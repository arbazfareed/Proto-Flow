# Layer tree and z-order

The layer tree mirrors the widget hierarchy on the active screen, including nested groups and containers. Select a layer to select its widget, rename it for clarity, and use visibility and lock controls to manage the canvas.

Reorder layers to change which widgets appear above others. Grouping and nesting help organize complex screens; expand or collapse groups to focus on the relevant parts of the design. Locked layers remain selectable in the tree but cannot be moved accidentally on the canvas.

If a widget is obscured, inspect the layer order and visibility before changing its geometry. Layer changes are part of the project and can be undone.
