# Device frames overview

Each screen can use a device preset or custom viewport size. A device frame adds a device-shaped presentation around the screen and can include a status bar, safe-area insets, and orientation. These are editing and preview aids; the screen's viewport remains the area where widgets are laid out.

Choose **Change device** from a screen's menu to pick a preset, search by device name, or define a custom width, height, pixel ratio, and insets. The view options control whether the frame and safe-area guide are visible.

Device presets are viewport references, not physical-device emulation. Check **Adding a device to a screen**, **Orientation**, and **Safe areas and snapping** for setup details.
