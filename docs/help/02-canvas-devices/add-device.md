# Adding a device to a screen

Use **Add screen** and choose a device category, or open a screen's menu and select **Change device**. The device picker supports search, category filters, recently used presets, and a custom size. Selecting a replacement device offers a choice about scaling widgets to the new viewport.

Choose a device that matches the layout you want to design. The preset's viewport dimensions are used by the canvas and responsive layout tools. You can later change the device without changing the project's screen identity.

If a new viewport causes content to fall outside the visible area, inspect the screen at the target breakpoint and adjust widget geometry or responsive overrides.
