# Selection and transforms

Click a widget to select it. Drag the selection to move it, or use the selection handles to resize it. The inspector exposes exact geometry and rotation values when you need precise placement. Hold the supported modifier key shown in the canvas UI to temporarily bypass snapping.

Use Shift-click or a selection marquee to work with multiple widgets. Group related items from the canvas context menu, then move or transform the group together. Locked widgets cannot be moved accidentally; visibility and lock controls are also available in the layer tree.

Undo and redo are available in the top bar and through `Ctrl/Cmd+Z` and `Ctrl/Cmd+Shift+Z`. Changes made in the editor are part of project history.
