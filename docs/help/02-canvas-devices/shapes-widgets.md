# Shapes and widgets

Choose a tool from the element library, then drag on the canvas to create a shape or widget. Common keyboard tools include `R` for a rectangle, `O` for an ellipse, `T` for text, and `B` for a button. Tool shortcuts are listed in the Keyboard shortcuts quick action.

ProtoFlow includes primitive shapes and interface elements such as buttons, inputs, cards, and containers. Dragging an element-library item onto the canvas creates it at the drop point; a drop inside a compatible container can nest it in the layer hierarchy.

Double-click text-bearing widgets to edit their label. Select an image placeholder to choose an image or use its Image URL action. Use the inspector for more detailed content and style settings.
