# Grid, snapping, and smart guides

Open Canvas view options to show or hide the grid, choose its spacing and appearance, and control snapping. The grid is a visual aid; snapping controls whether dragged or newly created items align to it.

When enabled, smart alignment guides help line up a widget with nearby siblings. Hold **Alt** while dragging to temporarily override snapping. Use the canvas shortcuts `Ctrl/Cmd+'` for the grid and `Ctrl/Cmd+Shift+'` for snap.

Grid visibility and snap behavior are editor aids. They do not change the prototype's rendered appearance. Use the canvas zoom and fit controls to work at a comfortable scale.
