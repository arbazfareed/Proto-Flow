# Safe areas and snapping

Device safe-area insets describe regions that should remain clear of system UI such as a notch or home indicator. Toggle **Show safe area** in Canvas view options to display the guide while editing. For custom devices, set the top, bottom, left, and right inset values in the device picker.

Keep important controls inside the safe-area boundaries when designing for an edge-to-edge device. The guide does not automatically move widgets or constrain their geometry.

Grid snapping and smart guides are separate from safe areas. Snapping aligns widgets to the grid; smart guides help align widgets with one another. Use Alt during a drag to bypass snapping when needed.
