# Flow diagrams

Select **Flow** beside **Design** in the workspace toolbar to view the screen-navigation graph. Each node represents a screen; edges represent navigation actions. Select a node to open that screen in Design and select an edge to inspect its source interaction.

Drag a node's header grip to position it, or choose **Auto layout** to arrange the graph. Drag a source node's arrow handle to a destination node to create a navigation action. Existing edge labels can show conditions. Diagram positions are saved in the project and can be undone.

Export the diagram as SVG or PNG from the Flow toolbar. The [screen-flow guide](help:flow-diagrams) has further details.
