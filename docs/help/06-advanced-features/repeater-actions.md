# Repeater actions: set, add, remove, sort, filter

The rule builder provides actions for updating repeater data: set its dataset, add a row, remove a row, sort rows, and filter the displayed rows. Choose the repeater as the action target and provide values in the format requested by the action editor.

Use these actions to prototype list operations such as adding a task, removing a selected item, or sorting results. If a value is dynamic, use an expression and check its context. Invalid JSON or an unknown field can prevent an action from producing the intended row.

Test the initial dataset and each action in Preview. Repeater changes are runtime state and should not be confused with editing the saved template or initial data.
