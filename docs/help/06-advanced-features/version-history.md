# Version history and checkpoints

Open **Version History** to review saved checkpoints and automatic history entries. Create a named checkpoint before a large change when you want a recognizable restore point. Compare versions, preview the selected snapshot, and restore it when needed.

Restoring a checkpoint updates the active project; use undo if you immediately need to reverse the restore. A checkpoint is not a substitute for saving a separate backup file.

History is local to the project and device. Keep a separate `.pflow` copy for durable backups or before sharing a project externally.
