# Dynamic panels overview

A dynamic panel contains multiple named states, each with its own widget content. Select the panel to manage its states in the inspector. Add, rename, duplicate, reorder, or remove states, then choose **Edit active state** to work on that state's contents on the canvas.

Use a panel for tabs, expandable sections, onboarding steps, or other UI that changes without navigating to a different screen. Interaction rules can switch a panel to a selected state, and Preview renders the active state.

Panels can be nested, but keep the hierarchy understandable. Use the panel state selector and layer tree to confirm which content is currently being edited.
