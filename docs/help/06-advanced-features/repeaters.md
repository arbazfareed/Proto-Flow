# Repeaters overview

A repeater renders a template for each row in its dataset. Select a repeater to edit its dataset and template. Use repeated rows for lists, cards, menus, or other content with a common structure.

The dataset can be edited as structured rows or imported from CSV. Widget bindings in the repeater template connect displayed values to fields in the current record. Preview shows the repeated output.

Keep template geometry and row fields aligned: a missing field or invalid dataset can leave a binding empty. Repeater state and actions are covered in the dataset and actions guides.
