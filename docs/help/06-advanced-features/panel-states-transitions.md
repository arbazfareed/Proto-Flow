# Panel states and transitions

Each dynamic panel starts with a state. Add more states for alternate content, rename them to describe their role, and arrange them in a meaningful order. Selecting a state in the inspector changes which state's widgets are shown for editing.

In the rule builder, add a **Set panel state** action and select the target panel and state. Optional transition settings control how the state change is animated in Preview. A transition does not change which state is active or the layout of its widgets.

Preview the complete interaction and check each state. If a state is deleted or renamed, review rules that target it.
