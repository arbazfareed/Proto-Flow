# Rich text editor

Use the Rich Text editor when a single text widget needs multiple styles or emphasis. Select the text-bearing widget and open its rich-text editing control. Format the relevant text and confirm the result in the canvas and Preview.

Rich text is distinct from plain labels and text interpolation. Preserve only the formatting you need; complex inline styling can be harder to maintain across narrow breakpoints.

If the text overflows, check the widget bounds, font size, and responsive overrides. Rich text content is stored with the project and included in supported local export formats.
