# Widget annotations and notes

Add a note to a widget to record design intent, review feedback, implementation details, or an issue to resolve. Notes remain attached to their widget as the screen changes.

Open the Notes panel to search and manage notes across the project. Use priority and status to organize review work. The notes overlay can show which widgets have annotations while you work on the canvas.

Notes can be exported for sharing with collaborators. Do not put credentials, customer information, or other sensitive material in notes that you plan to share. See the [widget notes guide](help:widget-annotations).
