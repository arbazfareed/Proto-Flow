# Cloud publishing and collaboration

Cloud publishing creates a public preview link, consumes the displayed wallet credits, and is separate from local export. The current publish dialog explains the cost, size, and 30-day public expiry before publishing. Do not publish a project containing private or sensitive material.

Real-time collaboration also uses a cloud session. Session details, permissions, and expiry are shown in the collaboration dialog. Close a session when you are finished, and share its invite only with intended participants.

Both features require a network connection. For offline sharing, use a local HTML export or a `.pflow` project file instead.
