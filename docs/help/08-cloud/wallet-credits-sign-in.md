# Wallet, credits, and optional sign-in

Open the wallet from the top bar to see the balance, recent activity, and refill status. Local editing, saving, Preview, and local HTML export do not require credits. Optional metered cloud actions show their cost in the relevant interface.

The wallet supports a daily refill when eligible, subject to the balance cap and a working network connection. If the refill is unavailable, the wallet shows the next eligible time or explains the offline state.

You can use the local editor without signing in. Sign-in is only needed for account-linked services. Review the wallet dialog's data and privacy information before linking an account; never share a sign-in link.
