# Style inspector

Select a widget and use the Style inspector to adjust its visual properties, such as fill, border, opacity, and other supported styles. Available fields depend on the selected widget type. Some interface widgets also expose content-specific options in the Element properties section.

When multiple widgets are selected, the inspector indicates mixed values where their styles differ. Applying a value updates the eligible selection. Breakpoint-aware style fields can be overridden for the active responsive layout.

Use Preview to check how the final rendered widget looks and behaves. The editor canvas may show selection handles and guides that are not part of the prototype.
