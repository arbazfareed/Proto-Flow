# Text properties

Text-bearing widgets expose text size and formatting controls in the inspector. Select a text widget or a widget with an editable label, then adjust its font size and supported text styles. Double-click a text-bearing widget to edit its content directly on the canvas.

For richer formatting, use the Rich Text editor. It supports styled runs in a single widget and preserves those runs in the project. Plain text fields remain appropriate for short labels and simple UI copy.

Review long text at each intended breakpoint: font size, widget bounds, and available width all affect wrapping and clipping.
