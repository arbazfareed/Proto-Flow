# Geometry inspector

Select a widget to edit its position, width, height, and rotation in the inspector. Values are expressed in screen coordinates and can be entered directly for precise layouts. For a multi-selection, shared properties can be edited together.

The inspector reflects the active breakpoint. Editing geometry with a breakpoint selected can create a responsive override rather than changing the widget's base values. Check the active breakpoint label before changing dimensions.

When a widget appears missing, verify its visibility, dimensions, parent container, and position relative to the viewport. The layer tree can help you select nested widgets.
