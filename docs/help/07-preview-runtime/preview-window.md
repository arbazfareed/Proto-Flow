# Preview window

Choose **Preview** from the top bar or use `Ctrl/Cmd+P` to run the current project. Preview is separate from the editing canvas and allows you to test screen navigation, interactions, panel states, variables, and repeater behavior.

Use the preview controls to inspect the design at supported sizes and reset the runtime when you need to repeat a flow from its initial state. The saved project provides the starting values; state changes during a preview session are temporary.

If a rule does not run, verify the event, conditions, and action target in the inspector. Preview the screen from the intended start point and try the same input again.
