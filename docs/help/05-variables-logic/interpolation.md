# Text interpolation with double braces

Use `{{variableName}}` in supported text fields to insert a variable's current value into displayed text. For example, a greeting can read a name variable instead of duplicating a fixed value across screens.

Interpolation is intended for simple variable substitution. Use the expression editor's `[[...]]` syntax when you need operators, functions, or references to widget and repeater data.

Make sure the variable exists in the project or screen scope where the text is rendered. Preview the screen to verify the resolved text and its layout.
