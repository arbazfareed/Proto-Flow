# Variables: types and scope

Open the Variables panel to create and manage project and screen variables. Variables have a type and an initial value; use a type that matches the data you plan to store, such as text, number, or boolean.

Project variables are shared across screens. Screen variables belong to a particular screen and are useful for screen-specific state. Interaction rules can read and update variables during Preview.

Use the variable picker in rule and expression editors where available. Variable changes made by a running prototype are runtime state; they do not rewrite the saved project's initial values.
