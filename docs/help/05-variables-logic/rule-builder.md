# Rule builder: events, conditions, and actions

Select a widget and open its Interactions section to add a rule. A rule has a triggering event, optional conditions, and one or more actions. Conditions decide whether the action list runs; action order can matter when later actions use values changed earlier.

Supported actions include navigation, variable updates, panel state changes, and repeater operations. Use expressions for dynamic values. Drag action rows to reorder them and use the action menu to remove or replace an action.

Run the prototype in Preview to test the rule. The editor displays validation problems for incomplete rules; a target that no longer exists may need to be chosen again.
