# Interaction-local variables

Local variables belong to one interaction rule. Create them in the rule builder to hold temporary values used by that rule's conditions and actions without adding a permanent project or screen variable.

Use local state for intermediate calculations, values derived from the triggering widget, and short-lived control flow. Local variables are evaluated in the context of their rule and are not shared with unrelated rules.

When a value must persist across multiple interactions or screens, use a project or screen variable instead. Read more in the [local variables guide](help:local-variables).
