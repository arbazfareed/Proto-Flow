# Moving workflows from Axure RP or Figma

ProtoFlow supports common prototyping workflows such as multi-screen navigation, variables, rules, dynamic panels, repeaters, responsive breakpoints, Flow diagrams, annotations, and Preview. It is not a promise of one-to-one project-file compatibility: recreate the source design and verify behavior in the target app.

For Axure, map pages to screens, widget interactions to rules, dynamic panels to panel states, and repeaters to a template with a dataset. Compare expression syntax and test each workflow in Preview. Use the Axure workflow protocols as a migration checklist.

For Figma, treat frames as a visual reference and rebuild widgets and interactions in ProtoFlow. Translate variants into panel states or separate screens where appropriate. Check responsive behavior at target viewport sizes.
