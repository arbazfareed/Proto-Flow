# Install and first launch

ProtoFlow is a local-first desktop prototyping app built with React, TypeScript, Vite, and Tauri. Use a release installer for everyday use. To run the source checkout, install Node.js 20.19+ or 22.12+ and the Rust prerequisites for Tauri, then run `npm install` and `npm run tauri dev`.

On first launch, choose a workspace appearance and review the privacy choices. The onboarding wizard can create a starter project or open the interactive tutorial in a separate editable copy. Your current project is restored when you finish the tutorial.

Projects are saved as `.pflow` files on your device. Save or download a copy regularly; the editor does not require an account or cloud connection for local design work.
