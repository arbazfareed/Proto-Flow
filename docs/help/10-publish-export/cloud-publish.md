# Cloud preview publishing

Choose **Publish** to create a hosted preview link. The dialog shows the export size, cost, and the 30-day public availability period before you continue. Publishing requires network access and spends the displayed credits.

Anyone with the public link may be able to view the prototype while it is active. Remove private data and review screen content before publishing. The published preview is a rendered prototype, not an editable project file.

Use local HTML export when you need an offline bundle or do not want to create a public link.
