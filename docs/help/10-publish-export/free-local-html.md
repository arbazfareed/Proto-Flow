# Free local HTML export

The local HTML export is created on your device and does not require cloud publishing or an account. Choose **Export HTML** in the top bar, review the export options, and save the generated bundle to a location you control.

Open the resulting HTML locally to inspect the exported prototype. For responsive output, choose the responsive variant; for deliberately distinct viewport compositions, choose per-device variants.

Local export does not upload project content. Keep a `.pflow` file as the editable source because the exported HTML bundle is for viewing and sharing, not for round-tripping into the editor.
