# React and Tailwind export

For a comparison with responsive HTML, per-device variants, and image exports, see [choosing between responsive and per-device export](help:choosing-responsive-vs-per-device).

Choose **Export code** to generate a React/Tailwind project bundle from the prototype. The exported source is intended as a starting point for application development, not as a guarantee of production-ready behavior.

Review the generated components, dependencies, and package scripts before installing or running the output. Add your own application data, routing, tests, and accessibility behavior as needed.

Use HTML export for a self-contained prototype artifact. Use React/Tailwind export when you want to continue from generated source code.
