# Per-device variants

Choose per-device output when you want a separate HTML variant for each configured screen or target device instead of one responsive page. Device variants are useful when each target has intentionally different composition or device-specific content.

Before export, verify the target screens, device presets, and responsive overrides. Open each generated variant locally and check navigation, text wrapping, and viewport fit.

For a single bundle that adapts across widths, choose responsive HTML export. Compare the options in [responsive HTML export](help:responsive-html-export).

For guidance on when to use variants, images, or React output, see [choosing between responsive and per-device export](help:choosing-responsive-vs-per-device).
