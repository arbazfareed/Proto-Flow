# Relay messaging suite

[Download the editable ProtoFlow project](../demos/relay-messaging-suite.pflow) to import or share it.

The WhatsApp-inspired messaging prototype uses original Relay branding and includes four connected sections: Chats, Calls, Updates, and Settings. The Chats list opens a separate Conversation screen, with a back action to return. Use the navigation rail on desktop and tablet, or the labeled bottom navigation on mobile. Sending a message updates the sample status.

Each screen has Mobile (390 × 844), Tablet (768 × 1024), and Desktop (1440 × 900) breakpoints with per-widget responsive layout. Change the breakpoint in the editor to review each size, or open Preview and test the section links.

Open the downloaded `.pflow` file in ProtoFlow using **Open project**. It is an editable local project; no account or cloud connection is required.
