# Importing code

Choose **Import Code** in the top bar to open the local HTML/CSS/JavaScript editor and live preview. The preview refreshes 300 ms after the last edit.

The preview runs in an iframe with `sandbox="allow-scripts"` and no same-origin permission. Its Content Security Policy blocks network connections, external scripts, embedded frames, and form submissions. Inline JavaScript is allowed inside the isolated preview; treat pasted code as untrusted and do not use it to display secrets.

The preview also extracts unique computed background, text, and border colors plus text styles grouped by font family, size, and weight. After rendering, these appear under **Imported Tokens** in the left sidebar. Select an unlocked canvas element to apply a color token; select a text-capable element to apply a text style.

Use **Inspect elements** in the live preview to select an HTML node and bind its click to navigation to another project screen. Rendering saves the rule with both the canvas widget ID and imported DOM node ID; the normal Interactions inspector can edit it, and the ProtoFlow preview executes it.

**Render on Canvas** converts supported HTML text, controls, and containers into editable ProtoFlow widgets. It approximates normal flow, flex rows, and grid layouts. Supported `min-width`/`max-width` media rules are evaluated for the active screen's breakpoints and saved as per-breakpoint widget overrides, including reflow and visibility changes. Breakpoint artboards expand to fit imported content, so sections below the initial viewport remain in document flow instead of being compressed or overlaid at the viewport edge. Use **Active breakpoint** to inspect desktop, tablet, and mobile layouts; device selection alone does not switch the active responsive breakpoint. This is a bounded canvas translation, not a browser layout engine; inspect and refine the imported widgets for complex designs. The parser also produces a flat element AST with stable-in-result IDs, parent links, text, computed styles, and suggested Lucide icon names. The **Required Icons** row in the preview lists icons inferred from semantic elements such as video, table, links, and date inputs. After rendering, matching native widgets appear in the sidebar's **From imported code** section, grouped by their normal categories. The shortcut list stays available while editing this workspace session; click an entry to activate its drawing tool or drag it directly onto the canvas. A toast reports which new shortcuts were surfaced.

Basic CSS selectors and inline styles can set text color, background color, font family, font size, weight, line height, alignment, border radius, and spacing. A built-in utility dictionary recognizes common Tailwind classes (colors, text sizes/alignment, weights, spacing, and rounded corners) and Bootstrap classes (theme colors, button variants, font sizes/weights, alignment, and rounded corners). Values are normalized with `window.getComputedStyle` when available. This is a deliberately bounded subset, not a full Tailwind or Bootstrap engine. Gradients are approximated as solid fills. JavaScript runs in the isolated preview; only listeners explicitly converted in **JavaScript Events** become canvas interactions. Unsupported markup, pseudo-state styling, and complex CSS layout are not converted.

Imported layer names prefer an element's `id`, then its first class, then its tag name. The layer tree follows the imported DOM parent relationships, with direct `<body>` children at the top level; each row uses the tag's suggested Lucide icon (cards use `SquareStack`). Selecting a layer selects its corresponding canvas widget. Detected elements such as date inputs also surface matching tools in **From imported code**; a date input unlocks the Calendar tool.

HTML input is limited to 200 KB, CSS to 100 KB, and canvas conversion to 200 widgets. The import action adds widgets to the active screen and selects them for editing.

The **JavaScript Events** section uses Acorn to detect static `document.querySelector(...).addEventListener(...)` and `document.getElementById(...).addEventListener(...)` calls for supported DOM events. It offers conversion when a callback assigns a string literal to `event.target`/`event.currentTarget` text; the resulting ProtoFlow event rule performs that text update in Preview. Other callback logic remains JavaScript-only in the isolated code preview and is not translated.

After an import, moving or resizing its canvas widgets writes their geometry as inline styles in the saved HTML draft. Reopen **Import Code**, edit the HTML, and choose **Render on Canvas** to re-parse and update that imported widget group rather than adding duplicates. Other canvas widgets and screens are left unchanged.
