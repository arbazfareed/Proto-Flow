# Interactive tutorial

The bundled tutorial is a separate, editable copy of [interactive-tutorial.pflow](../demos/interactive-tutorial.pflow). Open it from **Help & updates → Open tutorial project**, or choose **Take the tour** on the last onboarding step.

The project contains Home, Details, Settings, and Dashboard screens. It demonstrates iPhone 15 and Desktop 1440 frames, a three-state dynamic panel, a five-row repeater, expressions, responsive breakpoints, a widget annotation, rich text, navigation rules, and a flow diagram.

The guided panel walks through 15 steps and includes an Axure comparison on every step. Several actions advance automatically; use **Next** when a step asks you to verify an action in Preview or try an optional cloud feature.

Starting the tutorial creates a fresh project copy and a **Tutorial start** version checkpoint. The bundled source is never edited. Your previous project and its recovery snapshot are restored when you finish or close the tour. If the tutorial is already open, choose whether to restart it from the Help entry.

Tutorial progress events use fixed names only; project names, widget content, and other user-entered values are not included.
