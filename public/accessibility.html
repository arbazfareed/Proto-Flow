ProtoFlow

Accessibility statement

ProtoFlow is working toward WCAG 2.1 AA accessibility. Automated accessibility checks run in browser and Windows desktop CI, and keyboard focus, reduced motion, and narrow-screen reflow are checked as part of the E2E suite.

Automated tools cannot confirm full conformance. Manual testing with screen readers and other assistive technologies is still required; conformance is not claimed until that testing is completed.

Known limitations

Some complex editing workflows, including canvas and advanced feature interactions, require additional manual assistive-technology validation. The release checklist tracks this work.

Report an accessibility barrier

Report an issue on GitHub. Include your operating system, app version, assistive technology (if applicable), steps to reproduce, and expected and actual behavior. Do not attach private project files or personal data.
